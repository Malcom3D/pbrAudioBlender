
# pbrAudioBlender
## [v0.3.0] - 2026-11-04

### Added
- Integrated `pbrAudioRender`, `pbrAudioShaders`, and `pbrAudioDAW` (with TUI) into the ecosystem.
- Added Viewport Panel integration, 3D viewport widgets GUI, and `viewRay` graphical preview.
- Added new acoustic rendering output options (Ambisonic, Surround, Stereo, ProLogic II, and Binaural with HRTF processing).
- Added new nodes for acoustic node trees, including spatial frequency response nodes, frequency response chart/curve nodes, frequency response files nodes, and node frequency points graphs.
- Added preset acoustic materials and `AcousticMaterialPreviewNode`.
- Added new collision and render data exporters with mesh validation and fixing, plus per-collection properties in the collision panel.
- Added metadata editing methods in `StorageEngine` and bz2 compression/decompression for classes saved by `KleptoEntityStore`.
- Added helper for external NumPy loading and memory allocation tracking via Pympler.

### Changed
- Reworked `utils/frd_io.py` to parse `.cal`, `.csv`, and `.txt` files with cubic spline resampling.
- Handled track groups in processors to subdivide based on DAG node/edge goals.
- Switched `blosc2Backend` to parallel append and mmapped mode.
- Renamed relevant naming conventions from "Audio" to "Acoustic".

### Fixed
- Fixed Out-Of-Memory (OOM) issues in `ModalComposer`.
- Fixed data misalignments between signals and `ScoreEvent` from physics solver and rigid body modules.
- Fixed storage root paths, indentation errors, schema registration duplication, and missing module dependencies (`zarr`).
- Fixed material data export and ensured collision exporters discard non-connected nodes.
- Fixed single-object multi-collisions, mixed continuous contact, and fracture module integration.

# pbrAudioBlender
## [v0.3.0] - 2026-11-05

### Added
- **UI & Integration:** Integrated full Viewport Panel into `pbrAudioBlender`. Added new 3D viewport widgets for enhanced GUI interaction.
- **Node System:** Introduced a new `pbrAudioDAW` with TUI support. Added specialized nodes including `AcousticMaterialPreviewNode`, `FrequencyResponseChartNode`, and `SpatialFrequencyResponseNode`.
- **Rendering:** Implemented robust multi-format acoustic rendering options including Ambisonic, Surround, Stereo ProLogic II, and Binaural (Stereo w/ HRTF).
- **Processing:** Added new processors for mono modal displacement to acoustic pressure, and advanced audio forces denoising and signal smoothing.
- **Storage:** Integrated `blosc2` for efficient handling of large numpy arrays and added bz2 compression for `KleptoEntityStore` objects. Added methods for backend metadata editing.
- **Functionality:** Added ellipsoidal proxy module and advanced collision data exporters. Added preset acoustic materials.

### Changed
- **Performance:** Significant refactor of `StorageEngine` to support parallel appending and mmapped mode for the `blosc2Backend`. 
- **Compatibility:** Rolled back numpy to v1.26.4 (Blender default) for VFX reference platform compatibility, while adding a side-loading helper for numpy v2.3.5.
- **Architecture:** Complete code rewrite of `StorageEngine` and `render_exporter`. Modularized `PostProcess` classes into the `pbrAudioPostProcess` repository.
- **Naming:** Renamed global variables and classes from "Audio" to "Acoustic" for better domain accuracy.

### Fixed
- **Stability:** Resolved numerous "Out of Memory" (OOM) issues in the `ModalComposer`. Fixed multiple Python syntax and runtime errors including missing modules (`zarr`), incorrect indentation, and invalid naming conventions.
- **Data Integrity:** Fixed misalignment between signals and `ScoreEvent` data generated by `physicsSolver` and `rigidBody` components.
- **Cleanup:** Fixed device leakage in `AcousticMaterialPreviewNode` after playback. Fixed redundant schema registration in `Blosc2Backend`.
